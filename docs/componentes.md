# Componentes (`src/components/`)

Cada componente tem `.module.css` e, em geral, `.test.tsx`. Todos exportam `default` (os extras estão indicados). Convenção de nomes das props: `aberta`, `aoFechar`, `aoMudar`, `aoEditar`, `aoExcluir`, `nivel`, `rotulo`. `nivel` é a posição na pilha de folhas (0 = a primeira; folhas abertas por cima de outra usam 1 ou mais).

## Estrutura de página

| Componente     | Props                                                                               | O que faz                                                                                                                                                                                                                     |
| -------------- | ----------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Pagina`       | `titulo, tituloVisivel = true, acao, painel, controles, estreita = false, children` | Esqueleto de toda tela. `acao` é o botão do canto; `painel` e `controles` são regiões extra; `estreita` limita a largura (Definições). Exporta também `Kpis({ children, pagina })` e `EstadoVazio({ Icone, mensagem, sub })`. |
| `Kpis`         | `children, pagina?`                                                                 | Faixa de `KpiCard`; `pagina` serve para escolher o número em destaque (`chaveEmDestaque`, configurado em Definições). Vive em `Pagina.tsx`.                                                                                   |
| `EstadoVazio`  | `Icone (LucideIcon), mensagem, sub?`                                                | Ícone, mensagem e subtexto para listas vazias. Vive em `Pagina.tsx`.                                                                                                                                                          |
| `AbaTransicao` | `aba, children`                                                                     | Envolve o conteúdo de uma aba; remonta ao trocar de `aba`.                                                                                                                                                                    |
| `QuadroResumo` | `rotulo, idRotulo?, destaque = false, children`                                     | Cartão de resumo com rótulo. Exporta também `ValorGrande({ texto, cor?, discreto })` e `NotaDoQuadro({ children })`.                                                                                                          |
| `KpiCard`      | `rotulo, chave?, valor, sub?, tom = "neutro", discreto = false, aoClicar?`          | Um indicador (tipo `PropsKpi`). `discreto` aplica o modo discreto.                                                                                                                                                            |
| `ChipVariacao` | `sentido (-1\|0\|1\|null), texto, pior (boolean\|null)`                             | Chip de variação com cor conforme melhorou ou piorou. Só a Análise usa.                                                                                                                                                       |
| `Paginador`    | `pagina, paginas, aoMudar`                                                          | Setas e «N / M». Usado por `ListaLancamentos`, `Transacoes` e `Tvde`.                                                                                                                                                         |

## Listas e linhas

| `UltimosMovimentos` | (sem props)                                                                                                                                                                                                            | Os últimos movimentos do mês do seletor (Início).                                                                                                                                                                                                                                                                                                     |
